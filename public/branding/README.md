# Branding placeholders

GM trademarks (crossed flags, "Stingray" script, Corvette wordmark) are **not** included. Every emblem in the app is a
clearly labeled development placeholder ("C7" text on a plain badge). To use licensed artwork, drop PNG files here and
map them in `src/scene/Cockpit.tsx` (`makeTextDecal`) and `tools/blender/parts/steering.py` (emblem badge).
