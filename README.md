# C7 Interior Studio

A browser-based 3D customization simulator for the **2019 Chevrolet Corvette Stingray (C7) 3LT** interior. Sit in the
driver or passenger seat of a recreated cockpit, look and move around in first person, click any part to change its
material, color, stitching and replacement geometry, light the cabin with RGB zones and a starlight headliner, and keep
any number of independent projects in your browser.

> **Accuracy note.** The cockpit is a *scripted recreation* built in Blender from published C7 dimensions and reference
> descriptions, not a scan or a licensed GM model (no free, redistributable C7 interior model exists). GM emblems are
> development placeholders. See `docs/REFERENCES.md` and `docs/KNOWN-LIMITATIONS.md`.

## Quick start

```bash
npm install
npm run dev        # http://localhost:5173
```

Production build and preview:

```bash
npm run build      # typecheck + bundle into dist/
npm run preview    # serve dist/ on http://localhost:4173
```

Tests:

```bash
npm test           # unit tests (vitest): store, registry, presets, randomizer, schema, import/export
npm run test:e2e   # browser walkthrough (needs `npm run preview` running; see tests/e2e.cjs)
```

## Deploying

The build uses a relative base path, so `dist/` works on GitHub Pages, Netlify, Vercel or any static host.
A GitHub Actions workflow (`.github/workflows/pages.yml`) builds the app on pushes to `main` and publishes `dist/` to
the `gh-pages` branch, which GitHub serves at **https://tylerrini85-cyber.github.io/c7-interior-studio/**.

## Rebuilding the 3D assets

All geometry is generated by Python scripts in `tools/blender/` (Blender 4.0+, headless):

```bash
npm run models          # exports public/models/c7-cockpit.glb and public/models/variants/*.glb
npm run models:render   # check renders into docs/renders/ (needs xvfb on a headless Linux box)
```

`tools/blender/layout.py` holds every packaging dimension (seat position, wheel, dash, console, roof). Parts live in
`tools/blender/parts/`. Node names in the GLB are the component ids used by `src/registry/components.ts`.

## How projects are stored

Projects are structured JSON documents (`src/project/schema.ts`, schema version 1) saved in the browser's IndexedDB
(`c7-interior-studio` database) through `src/persistence/db.ts`. Every change autosaves about one second after it
happens; the top bar shows the save state. Thumbnails are captured from the live canvas. Projects can be exported and
imported as `.c7studio.json` files from the Garage, which is the recommended backup across browsers and devices.
The schema has a migration entry point (`migrate`) so future versions can read old files. No account or server is
needed; the architecture keeps a `ProjectDoc` as the single source of truth so a cloud sync could be added later.

## Architecture

See `docs/ARCHITECTURE.md`. In short: React 19 + TypeScript + Vite, three.js / React Three Fiber / drei, Zustand with
immer for state and undo/redo, a material engine that converts part configurations into physically based materials with
procedurally generated textures, a mesh registry that maps GLB nodes to component ids for selection and variant
swapping, and post-processing (N8AO, SMAA, selection outline) gated by quality presets.

## Controls

Drag to look, `W A S D` to move, `E`/`Space` up, `Q`/`C` down, arrows rotate (configurable), wheel zooms, `R` returns to
the seat, `H` hides the interface, `F` showroom mode, `Ctrl/⌘ Z` undo, `Ctrl/⌘ Shift Z` redo, `Ctrl/⌘ S` save,
`P` screenshot, `Esc` deselect. On phones: joystick to move, drag to look, bottom sheets for parts/lighting/camera.
